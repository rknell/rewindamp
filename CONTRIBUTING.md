# Contributing to Jellyamp

Contributions are welcome! Jellyamp was vibe coded with AI assistance and grew out of a
simple idea: make it effortless to build a queue or playlist from a Jellyfin collection,
especially when you want to put a party mix or a quick vibe together.

## Ways to help

- Fix bugs and improve playback, scrolling, search and queue management.
- Make playlist building faster without interrupting the current song.
- Improve accessibility, touch targets and the classic player interface.
- Test on real Android phones, Bluetooth outputs and Android Auto head units.
- Improve documentation or share reproducible reports using fictional music metadata.

Please keep queue-first behaviour intact: adding tracks appends to the queue, and ordinary
browsing must not replace it or unexpectedly resume paused playback.

## Build locally

Use JDK 17 and an Android SDK with platform/build tools 35. Set `ANDROID_HOME`, or create an
untracked `local.properties` with your SDK path. Then run from the repository root:

```sh
./gradlew assembleDebug lintDebug
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.
On Windows, use `gradlew.bat`. A local debug signing key is generated by Android tooling;
never commit signing keys. Builds from different signing keys do not update one another.

## Integration checks

With an Android emulator running, Docker, ffmpeg and Python 3 installed:

```sh
./scripts/integration-test.sh
```

The script starts its own disposable Jellyfin server on loopback port 18096 and generates
synthetic audio. The test credentials are intentionally fake and used only by that disposable
server. Tests assume the standard Android emulator host alias `10.0.2.2`.
The fixture directory is printed for inspection; the container is removed on exit.
Extra arguments are passed to Gradle for focused instrumentation runs.

Never point these tests at a live Jellyfin server or real music collection. Do not commit
passwords, tokens, cookies, server configuration, downloaded music or app-private databases.

## Pull requests

Describe the problem, the resulting behaviour and how you checked it. Keep changes focused,
run checks relevant to your change, and include screenshots or a short recording for UI work
when useful. Report device, Android and Jellyfin versions for playback or integration bugs.
Use fictional metadata and remove private information from logs and images.

AI-assisted contributions are welcome. Review generated changes, understand what they do,
and validate the behaviour before submitting them. Contributions are made under this
repository's MIT License; third-party code must retain its applicable licence and notices.
