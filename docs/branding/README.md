# Rewindamp icon

`rewindamp-pixel.png` is the approved transparent pixel-art brand master.
The Android adaptive icon uses a nearest-neighbour scaled copy, padded to keep
its orbit inside launcher masks, over a separate deep-purple background layer.
The transparent master remains usable on other backgrounds.

The simple vector `ic_rewindamp` remains the tintable Android Auto attribution
icon; the full-colour artwork is used for the application launcher.
