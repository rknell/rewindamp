# Rewindamp 0.4.24

Linux now reconnects once from the current playback position if a music or podcast stream is interrupted. If playback still cannot continue, Rewindamp keeps the position and displays an error. An interrupted episode stays unfinished.

The isolated Linux integration tests reproduced a truncated audio stream, verified that playback resumed and completed after a single drop, and verified that repeated drops preserved position without marking the item complete. The Android debug build and lint also passed.
