# Rewindamp 0.4.21

Linux now ships as an x86-64 AppImage with an embedded GitHub Releases update source. Add it to Gear Lever to integrate it and check for new stable versions. The AppImage uses the same queue, downloads and keyring entry as the earlier Debian package.

[Linux installation and updates](https://github.com/rknell/rewindamp/blob/main/linux/README.md)

Validated isolated Jellyfin and podcast integration, AppImage playback and desktop controls, Gear Lever integration, and the Android debug build and lint.
