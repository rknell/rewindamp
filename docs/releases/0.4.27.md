# Rewindamp 0.4.27

On Android, reopening an unfinished podcast now shows the time left and the saved progress before you press Play. If the feed does not include a duration, Rewindamp reads it from the audio while the episode stays paused.

The Android emulator tests verified the paused clock and progress bar after reopening, including playback preparation for episodes without a feed duration. The Android debug build and lint and the isolated Linux integration suite passed.
