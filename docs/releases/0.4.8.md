# Rewindamp 0.4.8

- Load complete music collections and search results without scroll-triggered pagination.
- Jump by initial using a metal rotary thumbwheel with a green letter window and tactile
  detents; the selector follows ordinary list scrolling too.
- Tap the podcast clock to switch between elapsed and remaining time, with the choice saved.
- Includes the podcast deck, separate Rewindamp Server connection, listening queues,
  sleep timer, phone downloads and Bluetooth seek controls developed since the last release.
- GitHub Releases are now the standard delivery channel for Obtainium updates.

Requires Android 8.0 or newer. Podcasts require a separately configured Rewindamp Server;
music uses your own Jellyfin server. This debug-signed build updates existing `dev.rewindamp`
installs signed by the same build host. Old Jellyamp installs use a different app ID.

Validation: JDK 17 debug build and Android lint; four focused Android 15 emulator checks
covering complete collection loading, cached retry, letter-wheel navigation without network
requests, exact browse restoration, and title/artist search deduplication. Integration checks
used an isolated Jellyfin container and synthetic data. Physical-device checks remain manual.
