# Rewindamp 0.4.14

- Open the **⋮** menu at the top of a playlist and choose **Add all to queue**. You no longer need to scroll to the last track to queue a playlist.
- The same action is available in album and track views. It appends in the displayed order, preserves the current queue and leaves paused playback paused. The existing end-of-list ADD ALL shortcut remains available.

Validation: JDK 17 / Android SDK 35 debug build and lint passed. Local emulator runs were interrupted by emulator process crashes. Publication is gated on the isolated Android 15 playlist-menu, car and podcast regression checks, including all 225 playlist entries appended in order without replacing a paused queue.
