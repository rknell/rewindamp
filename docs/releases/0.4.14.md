# Rewindamp 0.4.14

- Open the **⋮** menu at the top of a playlist and choose **Add all to queue**. You no longer need to scroll to the last track to queue a playlist.
- The same action is available in album and track views. It appends in the displayed order, preserves the current queue and leaves paused playback paused. The existing end-of-list ADD ALL shortcut remains available.

Validation: JDK 17 / Android SDK 35 debug build and lint passed. All six isolated Android 15 playlist-menu, car and podcast regression tests passed locally, including all 225 playlist entries appended in order without replacing a paused queue. The hosted playlist check also passed; an unrelated hosted car reconnect check timed out. Published through the documented local release script with the existing signing certificate after the complete local suite passed.
