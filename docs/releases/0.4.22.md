# Rewindamp 0.4.22

Linux now shows a **Podcast sign-in failed** dialog with steps to recover. It
explains when an address does not accept podcast sign-in, when to check your
credentials, and when to wait before retrying. **Try again** keeps your address
and username and asks for your password again.

Verified with an isolated HTTP 405 fixture, the Linux integration suite, and
the Android debug build and lint.
