# Rewindamp 0.4.25

The Android podcast media card has dedicated **15 seconds back** and **30 seconds forward** buttons beside Play/Pause. Both seek within the current episode. Car Bluetooth next and previous buttons continue to seek within the episode.

Android 15 emulator coverage checks the system media actions and simulated Bluetooth transport, including a queue with several episodes. The Android debug build and lint and the self-contained Linux integration checks passed.
