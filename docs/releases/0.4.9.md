# Rewindamp 0.4.9

A quieter library panel with more room for music and remembered places to return to.

- The right-hand metal letter wheel fills the list panel vertically, without a Letter heading.
- A horizontal metal wheel replaces the bottom buttons. Swipe it or tap a side to switch
  between Music, Podcasts and Queue.
- Queue is a separate destination. Return to Music to recover the exact library, album or
  search view and pixel scroll position, including after Android recreates the Queue screen.
- Tracks and artists appear immediately from a private, account-scoped local catalogue on
  subsequent launches. The full catalogue updates silently in the background, preserving
  the visible track even when earlier entries change. Saved empty catalogues also open instantly.
- Pull down at the top of a list to refresh. Existing rows remain usable if the server is offline.
- One control row now sits directly below the library header. The count lives in the status
  bar and gives way to newer messages. Background updates respect newer status messages.
- Removed the reload and SEL controls and per-track plus buttons. Hold a track for actions,
  including optional multi-selection. Playlist actions and view downloads are in the ⋮ menu.
- Add all is at the very end of the track list.

Validation: JDK 17 debug build and Android lint, plus ten focused Android 15 emulator checks
covering complete collection loading, cache refresh and account isolation, empty caches,
actual pull gestures and offline retry, exact queue/search/album restoration, podcast
navigation, activity recreation, letter-wheel navigation, long-press actions, the list footer,
queue append/clear/undo and search with the software keyboard visible. Only disposable
Jellyfin and generated fixtures were used. Physical-device checks remain manual.

The application ID and signing certificate are unchanged from 0.4.8. Obtainium users can
update from the same GitHub source: https://github.com/rknell/rewindamp.
