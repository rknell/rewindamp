# Rewindamp 0.4.18

## Linux

The first native desktop package is available for amd64 Debian-family Linux. Rewindamp
includes Jellyfin music and playlists, local queues and downloads, Rewindamp podcasts,
Mixarr, equalization and Linux media controls. See the [Linux guide](https://github.com/rknell/rewindamp/blob/main/linux/README.md)
for setup.

Linux validation covered the disposable Jellyfin and podcast servers, synthetic Mixarr
requests, FFmpeg playback and crossfade, and playing, pausing and restoring the queue
from the packaged app.

## Android

- Android skips spectrum analysis while the player display is hidden. Equalizer settings still apply in background playback.
- Android and Linux share server clients, podcast listening history, playback reporting, podcast subscription rules, YouTube chapter validation and equalizer processing.
- The low-power PCM bypass handles the empty buffer Media3 sends when draining playback.

The GitHub Android release workflow builds and lints with JDK 17 and SDK 35, runs the EQ
and spectrum tests plus the car, podcast and library smoke cases on Android 15, and checks
the published APK's package identity and existing signing certificate.
